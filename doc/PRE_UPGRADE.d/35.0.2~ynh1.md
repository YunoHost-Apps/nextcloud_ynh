TL;DR: If users' home directories in Nextcloud was enabled, this upgrade will move file and directory from /home/$user to /home/$user/Documents for all users, which **may take a long time**.

To prepare future migration to Debian 13 Trixie, user home folders have to be moved to a subfolder "Documents". If user home was enabled, continuing with the upgrade will move the content oh /home/$user to /home/$user/Documents for all users. This might take a long time.

In case the admins have installed several Nextcloud instances, they should:

1. Switch all Nextcloud instances to maintenance mode
2. Upgrade all Nextcloud instances successively, being aware that the upgrade of the first instance will move all the files and directories from /home/$user to /home/$user/Documents and therefore is likely to take long if some nextcloud instances enabled the "user_home" option.
3. Go out of maintenance status for all Nextcloud instances

In case the admins have custom mount points, please read [this documentation on forum.yunohost.org](https://forum.yunohost.org/#FIXME).
